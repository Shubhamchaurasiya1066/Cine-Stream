# 🎬 CineStream — Movie Explorer App

CineStream is a premium React + Vite movie discovery web application built using the TMDB API.

Users can:
- Browse trending/popular movies
- Search movies dynamically
- Watch movie trailers
- Experience a Netflix-inspired UI

---

# 🚀 Features

## ✅ Phase 1 Features
- TMDB API Integration
- Popular Movies Fetching
- Search Functionality
- Responsive CSS Grid Layout
- Premium UI Design
- Movie Ratings & Release Year

## ⭐ Advanced Features
- Clickable Movie Cards
- YouTube Trailer Modal
- Autoplay Trailers
- Fallback Poster Images
- Glassmorphism Navbar
- Responsive Design

---

# 🛠 Tech Stack

- React.js
- Vite
- Axios
- TMDB API
- CSS3

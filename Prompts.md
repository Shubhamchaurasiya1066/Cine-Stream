# Prompt Documentation

This document contains the prompts and learning references used during the development of the CineStream project.

---

## Prompt 1

How can I structure a React movie application using reusable components like Navbar, SearchBar, and MovieCard?

Purpose:
- Understand component architecture
- Improve folder structure
- Learn reusable UI design

---

## Prompt 2

How do I fetch popular movie data from TMDB API using Axios in React?

Purpose:
- Learn API integration
- Practice async/await
- Understand API response handling

---

## Prompt 3

How can I create a responsive movie grid layout using CSS Grid?

Purpose:
- Improve frontend UI skills
- Learn responsive design
- Build modern layouts

---

## Prompt 4

How do I implement a movie search feature using TMDB search endpoint?

Purpose:
- Learn controlled inputs
- Handle dynamic API requests
- Render filtered movie data

---

## Prompt 5

How can I open a movie trailer inside a React modal using YouTube iframe?

Purpose:
- Learn modal handling
- Improve user interaction
- Understand conditional rendering

---

## Prompt 6

How do I handle missing movie posters gracefully in React applications?

Purpose:
- Prevent broken UI
- Improve user experience
- Learn fallback rendering

---

## Prompt 7

How can I improve the UI of a React movie application to make it look more modern and premium?

Purpose:
- Learn UI enhancement
- Practice hover effects and gradients
- Improve visual presentation

---

# Development Approach

The project was developed by understanding concepts step-by-step and implementing them manually while using AI assistance only for learning, debugging, and architectural guidance.
